# BetterWiFi RH — Wi-Fi Tools for iOS 16 RootHide

**BetterWiFi RH** is a RootHide-compatible jailbreak tweak for **iOS 16** that expands the Wi-Fi information and diagnostic tools available in Settings.

**BetterWiFi RH** es un tweak de jailbreak compatible con **RootHide** para **iOS 16** que amplía la información y las herramientas de diagnóstico Wi-Fi disponibles en Ajustes.

> Current version / Versión actual: **0.3.8** · Architecture / Arquitectura: **iphoneos-arm64e**

## Español

### Qué hace

BetterWiFi RH añade información ampliada de la red Wi-Fi conectada, monitorización de señal en tiempo real, historial/gráfica de señal, análisis de canales y filtros adicionales dentro de la interfaz Wi-Fi de Ajustes. Está adaptado para el entorno **Dopamine + RootHide** y evita mantener un daemon residente dedicado.

### Funciones

- Información ampliada de la red Wi-Fi conectada.
- Monitor de señal en tiempo real.
- Historial/gráfica de señal mientras la pantalla correspondiente está abierta.
- Analizador de canales Wi-Fi.
- Información de redes de 2,4 GHz y 5 GHz.
- Filtros clásicos para la lista de redes.
- Herramientas de diagnóstico.
- Integración con Shuffle.
- PreferenceBundle en Ajustes.
- Compatibilidad con RootHide.
- Sin daemon residente dedicado.

### Compatibilidad

- iOS 16.x
- Dopamine / RootHide
- iPhone arm64e
- PreferenceLoader
- Sileo
- Paquete: `iphoneos-arm64e`

## English

### What it does

BetterWiFi RH adds richer connected-network information, live signal monitoring, signal history/graphing, Wi-Fi channel analysis and extra network filters inside the Settings Wi-Fi interface. It is adapted for the **Dopamine + RootHide** environment and does not rely on a dedicated resident daemon.

### Features

- Extended connected Wi-Fi network information.
- Live Wi-Fi signal monitor.
- Signal history/graph while the relevant page is open.
- Wi-Fi channel analyzer.
- 2.4 GHz and 5 GHz network information.
- Classic network filtering options.
- Diagnostic tools.
- Shuffle integration.
- Settings PreferenceBundle.
- RootHide compatibility.
- No dedicated resident daemon.

### Compatibility

- iOS 16.x
- Dopamine / RootHide
- arm64e iPhones
- PreferenceLoader
- Sileo
- Package architecture: `iphoneos-arm64e`
