# Tweaks

Each project in GokuEnREPO has its own directory here.

- [BandLock](BandLock/) — source snapshots, release packages, diagnostics, documentation and depiction.
- [BetterWiFi RH](BetterWiFi-RH/) — release package, documentation, changelog and depiction.
- [Nuke Wireless](Nuke-Wireless/) — documentation and depiction while development is ongoing.

Repository-wide APT metadata remains at the repository root so the existing Sileo/Cydia/Zebra/Installer source URL does not change.
