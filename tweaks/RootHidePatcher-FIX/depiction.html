RootHidePatcher FIX

1.0.0 RootHide

Prevents duplicate library search paths when RootHidePatcher converts a tweak that already contains both rootless and RootHide paths.

Requires RootHidePatcher 2.1.4. Install this fix, then convert the original DEB normally. No respring is needed.

Previously converted packages must be converted again from their originals. This package does not change your installed tweaks or app data.

Removing the fix restores the original converter. Unknown or custom converter scripts are preserved.

By Gokuencinar. Independent fix for RootHidePatcher.
