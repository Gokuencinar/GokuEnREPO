# GokuEnREPO

Repositorio APT público para Sileo orientado a tweaks y paquetes compatibles con RootHide.

## Fuente para Sileo

```
https://raw.githubusercontent.com/Gokuencinar/GokuEnREPO/main/
```

## Paquetes actuales

- **BandLock 0.4.4** (`iphoneos-arm64e`) — permite consultar y seleccionar bandas LTE, usar perfiles rápidos y cambiar el modo de red desde Ajustes. **Compatible con iOS 16.x + RootHide/Dopamine**.
- **BetterWiFi RH 0.3.8** (`iphoneos-arm64e`) — amplía las herramientas Wi‑Fi de iOS con información de la red conectada, monitorización, diagnóstico, filtros e integración con Shuffle. **Compatible con iOS 16.x + RootHide**.

El índice `Packages` y `Packages.gz` se regenera automáticamente cuando cambia cualquier archivo dentro de `debs/`.

## GitHub Pages

El workflow de Pages está preparado, pero GitHub Pages debe habilitarse una vez desde **Settings → Pages → Source: GitHub Actions** antes de ejecutarlo.
